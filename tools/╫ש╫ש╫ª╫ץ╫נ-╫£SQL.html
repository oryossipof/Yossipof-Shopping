🛒 ייצוא רשימות הקניות

שולף את כל הנתונים מהמסד הישן ומייצר פקודות SQL מוכנות להדבקה במסד החדש.

המסד הישן

הערכים כבר מולאים מהפרויקט שלך. אין צורך לשנות דבר.

התוצאה

מה עושים עכשיו

  1. נכנסים לפרויקט ה-Supabase החדש שלך
  2. בתפריט הצדדי: SQL Editor → New query
  3. מוודאים שכבר הרצת שם את supabase/setup.sql — אחרת הטבלאות לא קיימות
  4. מדביקים את כל מה שהעתקת ולוחצים Run
אפשר להריץ את הפקודות פעמיים בלי חשש — שורות שכבר קיימות פשוט ידולגו.
